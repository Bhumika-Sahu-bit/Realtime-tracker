# 🌍 Real-Time Location Tracker

A full stack **Real-Time Location Tracker** web application built with **Node.js, Express, Socket.IO, EJS, and Leaflet.js**.  
This project allows users to share and view locations in real time on an interactive map — ideal for tracking friends, teams, delivery personnel, or devices.

📍 Live Demo:  
👉 https://real-time-location-tracker-c3kd.onrender.com/

---

## 🛠️ Features

✔ Real-time location tracking using WebSockets  
✔ Interactive map using Leaflet.js  
✔ EJS templating for frontend views  
✔ Displays dynamic locations on the map  
✔ Works in modern browsers with geolocation support  
✔ Responsive and clean UI

## 🧠 Tech Stack

This project uses:

- **Node.js** – Backend runtime  
- **Express.js** – Web framework  
- **Socket.IO** – Real-time bidirectional communication  
- **EJS** – Embedded JavaScript templating for views  
- **Leaflet.js** – Interactive maps with markers  
- **HTML5 & CSS3** – Frontend structure & styling
